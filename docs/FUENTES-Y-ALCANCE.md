# Límites del caso de estudio

## Distinciones necesarias

- El plan de **183,002 cajas** no equivale por sí mismo a un resultado ejecutado y auditado.
- «Arquitectura a utilizarse» (pág. 18) es una **propuesta**, no evidencia de implementación de Data Lake o Machine Learning.
- Los módulos descritos en futuro (págs. 21–22) no se declaran entregados sin evidencia adicional.
- La presentación no especifica stack de software, versiones, alcance contractual, presupuesto total, fecha de puesta en operación ni indicadores de rendimiento.
- El caso no implica que el autor o Plenumsoft fueran los únicos responsables de la Litoteca, desarrollada por un consorcio.

## Propiedad intelectual

El repositorio no publica el PDF corporativo completo, código fuente, configuraciones ni datos de muestras. El autor confirmó autorización para publicar las imágenes aportadas. Se incluyen dos **recreaciones asistidas por IA** (`docs/assets/litoteca-instalaciones.png` y `docs/assets/kalan-tun-dashboard.png`) como material de presentación. No deben interpretarse como fotografías originales, capturas exactas ni evidencia de funciones adicionales. Se mantiene además un encabezado SVG original.
